# AFRICA-BUSINESS-COACHING
Creation des logiciels pour les entreprises africaines

## Site web

Site vitrine multi-services (Paie & RH, transport, carburant, parkings, stations-service,
flottes, vente de véhicules, GPS) avec espace administrateur sécurisé et plateforme
d'éducation en ligne (collège → doctorat) par abonnement.

- Code du site : dossier `site/`
- Base de données Supabase : dossier `supabase/`
- Mise en ligne pas à pas : [docs/INSTALLATION.md](docs/INSTALLATION.md)
